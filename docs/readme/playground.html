The ambition: replace router firmware itself — OpenBSD-first, RAM-only, AI-driven, and locally governed. AI proposes. The machine proves. This page is only a synthetic authority-shape demonstration, not Rheknel, not a model run, and not a firmware release.

Why does the toy gate sometimes refuse?

Because not every graph has a permitted path. The toy solver excludes blocked links, excludes the tunnel unless you allow it, and the toy gate rejects the cheapest remaining path if it exceeds your policy ceiling. A good interface should report that—not invent connectivity.

Where is Rheknel in this demo?

Nowhere. The “toy truth gate” is a deterministic stand-in for the authority shape only: a proposal is evaluated against local policy before it can be presented as admissible. Real Rheknel enforcement remains a target until the repository has direct receipts.

What does “rollback is sacred” mean?

The target system treats network changes as bounded transactions with an explicit way back. This page only recomputes a toy graph; it does not demonstrate watchdog survivability, router recovery, or fault injection.

Is this free internet, anonymity, or a working router OS?

No. “The internet is free. Again!” is the project manifesto: open access and operator control. ISP service and infrastructure still cost money. This simulation supplies neither connectivity nor anonymity, and it does not boot a router.
