The ambition: make the paid-tunnel workaround unnecessary for ordinary access. Keep encryption. Lose dependence. The current repository is an experimental Rust edge-agent reference implementation, not a released replacement for your VPN.

Why does the model sometimes refuse to connect?

Because not every graph has a permitted path. The model excludes blocked links, excludes the tunnel unless you allow it, and rejects the cheapest remaining path if it exceeds your budget. A good interface should report that—not invent connectivity.

What does “rollback is sacred” mean?

The project is designed around bounded changes and an explicit way back. This page only recomputes a toy graph; it does not demonstrate the runtime's transaction safety, watchdog operation, or recovery under fault injection.

Is this free internet, anonymity, or a working VPN?

No. “The internet is free. Again!” expresses the project's ambition of open access and operator control. ISP service and infrastructure still cost money. This simulation supplies neither connectivity nor anonymity. Keep your working security setup.
