# Agent Operational Directives

> **CRITICAL INSTRUCTION:** All autonomous agents interacting with this repository MUST adhere to the following operational lifecycle.

## 1. Continuous Source Control (Git)
You must keep `git` up to date even inside processing a single prompt. 
Before concluding any task, implementation, or significant debugging step, you MUST run:
```bash
git add .
git commit -m "chore: <brief description of changes>"
git push
```
Never leave the workspace with uncommitted changes after your turn.

## 2. Capability-Based Execution ONLY
The system operates on a strictly typed `CapabilityGraph`. Do not introduce raw shell strings (like `ip route` or `uci set`) anywhere outside of the `src/executor/` boundary. "Grep-based security" is considered safety theater and is banned. All mutations must be proven through the QEMU integration suite.

## 3. Hostile Environment Networking
Blueshoes operates in highly adversarial networks (state-level censorship). When designing network logic, assume Deep Packet Inspection (DPI), active probing, and SNI filtering are present. Always favor standardized obfuscation (like MASQUE, ECH, QUIC) over bespoke or easily fingerprinted protocols.
